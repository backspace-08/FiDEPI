# Архитектура

[← README](../README.md)

## Стек

| Слой | Что используется |
|---|---|
| UI | Vue 3.5, Composition API, `<script setup>` |
| Сборка | Vite 8 |
| Язык | JavaScript, ES-модули |
| Стили | CSS-переменные, scoped CSS, flex/grid |
| Графика | 68 SVG, слоистая сборка персонажей |
| Анимации | Web Animations API и CSS |
| Звук | Ogg Opus, Web Speech API как запасной вариант |
| Состояние | `localStorage` |

Роутера, UI-кита и стейт-менеджера нет: игра линейная, сцены переключаются по индексу в `App.vue`.

## Структура

```
src/
├─ App.vue                 # сцены, навигация, озвучка
├─ components/             # сцены, персонажи, письма, отчёты
├─ data/                   # вопросы, блоки, тексты, фразы
├─ lib/                    # scoring, assessment, audio
└─ avatars.js              # кропы аватаров

svg/
├─ layered/                # слоистые персонажи
└─ normalized/             # готовые фигуры и реквизит

public/
├─ audio/                  # 83 записи
├─ favicon.svg             # иконка сайта
├─ favicon-32.png
├─ favicon-192.png
└─ apple-touch-icon.png

docs/                      # методика, дизайн, озвучка, эта страница
base.css                   # дизайн-токены
index.html
```

## Сохранение

Семья хранится в `fidepi-family`, прогресс — в `fidepi-assessment`. Обе записи живут в `localStorage`; бэкенда нет. При перезагрузке на игровых сценах восстанавливаются доставленные письма и текущий вопрос.

Коды доступа к отчётам проверяются на клиенте. Это демонстрация, а не авторизация: любой, кто откроет исходный код, увидит коды.

## Деплой

GitHub Pages, workflow `.github/workflows/deploy.yml`. Сборка запускается пушем в `production`, `base` в `vite.config.js` — `/FiDEPI/`.

## Ограничения

Бэкенда, автотестов и линтера пока нет. Отчёты не выгружаются в PDF/CSV, ссылки родителю и психологу не отправляются.
